HOSTELHUB - HOSTEL MANAGEMENT SYSTEM
======================================

Files:
- index.html
- style.css
- script.js

Run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server (recommended), or double-click index.html.
4. Use the sidebar to explore Home, Students, Rooms, Fees, Complaints, Notices and Profile.

This is a frontend college project demo. Login/authentication and real payment gateway/database are not connected.
